# Hello, GitHub!

A basic static webpage for demonstrating GitHub with HTML, CSS, and JavaScript.
No installation or build step required.

## Open the page

Double-click `index.html` to open it in your browser.
Click **Click me** to increase the counter or **Reset** to start over.
Refreshing the page also resets the counter.

## Files

- `index.html` — page content and structure
- `styles.css` — colors and layout
- `script.js` — click counter behavior

## GitHub demo ideas

1. Create a GitHub repository and add these files.
2. Create a branch named `update-heading`.
3. Change the heading in `index.html` and commit the change.
4. Open a pull request and review the diff.
5. Merge the pull request and pull the latest changes locally.

For another small change, update `--accent` in `styles.css` or change the
counter increment in `script.js`. Refresh your browser to see your edits.
